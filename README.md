# 🌐 Disparador de Mensagens - Versão Web (SENAI)

Versão web do sistema disparador de mensagens integrada com banco de dados, desenvolvida para o projeto do SENAI.

## 🛠️ Tecnologias Utilizadas
- HTML5 / CSS3
- JavaScript (Front-end)
- Node.js (Back-end / Banco de dados)

## 📦 Como rodar o projeto localmente
1. Clone o repositório:
   ```bash
   git clone 

   ```

2. Instale as dependências necessárias (que foram omitidas pelo .gitignore):
   ```bash
   npm install
   ```
3. Inicie o servidor do banco/aplicação:
   ```bash
   npm start
   ```
